# CAPA Action Plan & Remediation Guide (คู่มือแผนปฏิบัติการแก้ไขและป้องกัน)

## ๑. วงจรการบริหารจัดการ CAPA (CAPA Lifecycle)

```
[ Compliance Gap Identified ]
            │
            ▼
[ Root Cause Analysis (5-Whys) ]
            │
            ▼
[ Formulate Corrective Action (Immediate) ]
            │
            ▼
[ Formulate Preventive Action (Systemic / SOP) ]
            │
            ▼
[ Assign PIC & Target Duration (Days) ]
            │
            ▼
[ Implementation & Verification of Effectiveness ]
            │
            ▼
[ Attach Evidence & Close CAPA ]
```

---

## ๒. ลำดับความสำคัญและกรอบเวลาการแก้ไข (Priority & Timelines)

| ระดับความสำคัญ (Priority) | กรอบเวลาเป้าหมาย (Target Days) | ตัวอย่างประเด็นข้อบกพร่อง |
|---|---|---|
| **CRITICAL** | ๓ - ๑๕ วัน | ทางหนีไฟมีสิ่งกีดขวาง, ไม่มี จป.วิชาชีพ, ขาดตรวจรับรองระบบไฟฟ้า/ปั้นจั่น/หม้อน้ำ |
| **HIGH** | ๑๕ - ๓๐ วัน | อบรมดับเพลิงไม่ถึง ๔๐%, ขาดการตรวจวัดสารเคมี/สิ่งแวดล้อม, การ์ดเครื่องจักรชำรุด |
| **MEDIUM** | ๑๐ - ๒๐ วัน | การส่งรายงานราชการ (จผ.๑, สอ.๓, จป.ท.๑), ป้ายเตือนอันตราย, บันทึกสมุด จปภ.๑ |
| **LOW** | ๓๐ - ๔๕ วัน | การปรับปรุงเอกสารทะเบียน OSH ภายใน |

## ๓. ผู้รับผิดชอบหลักตามสายงาน (Standard Person-in-Charge: PIC)

1. **กรรมการผู้จัดการ (MD) / ผู้บริหารสูงสุด**: นโยบายความปลอดภัย OSH, โครงสร้างหน่วยงานความปลอดภัย
2. **ผู้จัดการฝ่ายทรัพยากรบุคคล (HR Manager)**: การแต่งตั้ง จป. ทุกระดับ, การอบรมลูกจ้างใหม่, การตรวจสุขภาพกลุ่มเสี่ยง
3. **จป.วิชาชีพ / ผู้จัดการความปลอดภัย**: การตรวจวัดสิ่งแวดล้อม, แผนฉุกเฉิน, การส่งรายงานราชการ, ทะเบียนกฎหมาย
4. **ผู้จัดการฝ่ายวิศวกรรมและซ่อมบำรุง**: การตรวจรับรองไฟฟ้า, ปั้นจั่น (ปจ.๑/๒), หม้อน้ำ (บร.๑/๒), Machine Guarding, สายดิน
5. **หัวหน้าแผนก / ผู้ควบคุมงาน**: ป้ายเตือนอันตราย, การสวมใส่ PPE, ทางหนีไฟโล่ง, Checklists ประจำวัน
